# 🍳 Professional Cookbook Creation — Cowork Agent Master Prompt

## Mission

You are building a **complete, professional-quality cookbook** as a beautifully designed PDF. This cookbook should look like it belongs on a bookstore shelf — with stunning page layouts, AI-generated food photography, styled ingredient shots, cohesive typography, and a clear design system throughout. The final deliverable is a single, multi-page PDF cookbook.

## Phase 0: Research & Setup

Before creating anything, you need to research and install the right tools.

### Required Python Packages (install all)

```bash
pip install --break-system-packages reportlab pillow pdfplumber pypdf requests
```

### AI Image Generation

You need food photography for every recipe. Research and use one or more of the following approaches:

1. **Pollinations.ai** (free, no API key needed):
- Endpoint: `https://image.pollinations.ai/prompt/{prompt}?width=1024&height=1024&seed=42&nologo=true`
- URL-encode the prompt
- Download images with `requests.get()` and save as PNG/JPG
1. **Alternative free image APIs** — search the web for currently working free AI image generation APIs (Stable Diffusion endpoints, HuggingFace Inference API, etc.)
1. **Fallback**: If AI generation fails, search for high-quality Creative Commons food photography from Unsplash (`https://source.unsplash.com/`) or Pexels API

**For every recipe, generate TWO images:**

- **Hero shot**: The finished dish, beautifully plated, overhead or 45-degree angle, natural lighting, styled with garnishes
- **Ingredients shot**: A flat-lay arrangement of all raw ingredients, labeled or artfully arranged

### Image Prompt Engineering for Food Photography

When generating images, use prompts like:

> “Professional food photography of [dish name], beautifully plated on [plate style], [camera angle] shot, natural window lighting, shallow depth of field, styled with fresh herbs and garnishes, editorial quality, 4K, food magazine cover quality”

> “Overhead flat-lay of fresh cooking ingredients for [dish name] arranged on marble countertop, [list key ingredients], natural lighting, clean editorial food photography style”

## Phase 2: Design System

### Design Philosophy

Create a cohesive visual identity for the entire book. Before designing pages, write a short design philosophy document (save as `design-philosophy.md`) that covers:

- **Color palette**: Choose 4-5 colors. Suggestion: warm, rustic tones (deep charcoal, warm cream/off-white, burnt orange or paprika red, sage green, gold accent)
- **Typography**: Use 2-3 fonts max
  - **Headlines**: Bold, personality-driven (slab serif or hand-drawn feel)
  - **Body text**: Clean, readable sans-serif or serif
  - **Accents**: For callouts, tips, page numbers
- **Grid/Layout system**: Consistent margins, gutters, image placement zones
- **Visual motifs**: Recurring design elements (divider lines, icons, texture overlays)

### Page Types to Design

1. **Cover Page** — Title, author, hero image, beautiful typography
1. **Table of Contents** — Chapter listing with page numbers
1. **Chapter Divider Pages** — Full-bleed image or illustration + chapter title
1. **Recipe Pages** — Follow the template above (some single-page, some two-page spreads)
1. **Tip/Interstitial Pages** — Cooking tips, technique guides, or quotes
1. **Back Cover** — Author bio, closing image, tagline

### Layout Principles

- **White space is your friend** — Don’t crowd pages
- **Images should be large and bold** — Food photography is the star
- **Consistent alignment** — Use a grid system
- **Page numbers** on every page (except cover and chapter dividers)
- **Running headers** with chapter name

## Phase 3: Build Process

### Step-by-Step Execution

1. **Generate the design philosophy** → Save as `design-philosophy.md`
1. **Write all recipe content** → Save each chapter as a separate markdown file for reference
1. **Generate ALL images first** → Download and save to an `images/` directory
- Name convention: `chapter_recipename_hero.png`, `chapter_recipename_ingredients.png`
1. **Build the PDF page by page using ReportLab**:
- Use `reportlab.platypus` for structured layouts (SimpleDocTemplate or BaseDocTemplate with PageTemplates)
- Use `reportlab.pdfgen.canvas` for custom-drawn pages (cover, chapter dividers)
- Use `reportlab.lib.utils.ImageReader` for embedding images
- Register custom fonts if available (`pdfmetrics.registerFont`)
1. **Assemble into a single PDF** → Merge all pages in order
1. **Quality check** → Verify all images render, no text overflow, consistent styling
1. **Save final output** to `/mnt/user-data/outputs/cookbook.pdf`
